# حیدری پورتفولیوی امیر 

Next.js (App Router) + TypeScript + Tailwind CSS. تک‌صفحه‌ای، بدون هدر، بدون دیتابیس — استاتیک و قابل دیپلوی روی Vercel/Netlify.

## اجرا روی سیستم خودتان

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید. نیاز به هیچ متغیر محیطی یا دیتابیسی نیست.

> Node.js نسخه‌ی ۱۸.۱۸ به بالا لازم است.
